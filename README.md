## 🚀 Featured Projects

An IoT-based weather monitoring and early warning system developed in collaboration with BMKG Kelas I Radin Inten II Lampung. The system utilizes ESP32 and environmental sensors to collect and display real-time weather data.

**Technologies:** ESP32, IoT, Sensors, Web Dashboard

### Vigenère Cipher

A web-based application for text encryption and decryption using the Vigenère Cipher algorithm.

**Technologies:** HTML, CSS, JavaScript
